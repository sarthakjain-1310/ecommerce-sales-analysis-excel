# E-commerce Sales & Profit Analysis Dashboard

## 📊 Project Overview

An interactive E-commerce Sales & Profit Analysis dashboard developed using Microsoft Excel to analyze sales performance, profitability, customer behavior, product performance and discount patterns.

## 📁 Dataset

* **12,035 orders**
* **₹272.5M total sales**
* **₹45.0M total profit**
* Multiple categories, products and customers

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Data Cleaning
* Excel Formulas
* PivotTables
* Slicers
* KPI Cards
* Charts
* Sales & Profit Analysis

## 🔍 Analysis Performed

The dashboard provides analysis of:

* Monthly sales and profit performance
* Category-wise sales and profit margin
* Customer sales and profitability
* Product performance
* Discount impact
* Key business KPIs
* Sales and profitability trends

## 💡 Key Insights

* August recorded the highest sales, while July recorded the lowest.
* Electronics generated the highest sales among the categories.
* Fashion generated lower sales but had a higher profit margin than Electronics.
* Some customers generated high sales without being among the most profitable customers.
* High-selling products were not necessarily the highest-margin products.
* Higher discounts did not always result in proportionally higher profitability.

## 🎯 Project Objective

The objective of this project was to practice practical Excel-based data cleaning, analysis, reporting and interactive dashboard development for business and MIS reporting scenarios.
